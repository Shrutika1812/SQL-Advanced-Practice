# SQL Advanced Practice

A hands-on SQL practice repository covering advanced querying and database concepts using MySQL.

## Topics Covered

- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Indexes
- Views
- CASE expressions
- Window Functions
- Aggregations
- Interview-style SQL problems

## Database

Examples are written for **MySQL 8+**.
